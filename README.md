
# 🍔 Crib Burgers

**Crib Burgers** is a modern food brand focused on delivering bold flavors, convenience, and community-driven experiences.  
Our mantra is simple: **Give it. Eat.**  

This project powers the Crib Burgers digital experience, combining clean design with smart functionality.

---

## 🚀 Features

- Modern and responsive UI
- Fast performance with Vite
- AI-powered features (via Google Gemini)
- Mobile-first experience
- Easy customization and scalability

---

## 🛠️ Tech Stack

- **React (TSX)**
- **Vite**
- **Node.js**
- **Google Gemini AI**
- **Tailwind CSS**
